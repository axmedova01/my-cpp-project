## KR - Прототип программы расчета движения объектов под действием гравитации
Описание:
Запуск кода производится из файла main.cpp, который инициализирует приложение и открывает главное окно, где MainWindow.cpp отвечает за отрисовку небесных тел, управление циклом анимации и вывод статистики на экран. Логика симуляции находится в Galaxy.cpp: этот модуль генерирует начальную систему, рассчитывает силы гравитации между всеми парами объектов, обрабатывает их столкновения (слияния) и обновляет координаты. В Star.cpp описана модель отдельного небесного тела, которая хранит его физические параметры, а также динамически меняет цвет и размер объекта в зависимости от его массы.

## laba1 - Лабораторная работа по основам ООП в C++ с использованием абстрактных классов, наследования и полиморфизма на примере геометрических фигур.
Описание: В функции main() происходит случайная генерация фигур, их фильтрация по условию принадлежности области, после чего данные выводятся в консоль и сохраняются в текстовый файл. Файл output.txt содержит итоговые результаты работы программы — координаты, радиусы и размеры успешно прошедших проверку кругов и прямоугольников.

## Lab2 - Двумерная физическая симуляция движения и столкновения геометрических фигур с графическим интерфейсом на Qt.
Описание: Запуск приложения производится из main.cpp, а физическая модель, генерирующая массив случайных кругов и прямоугольников и обрабатывающая их отражения от границ поля и взаимные столкновения с уничтожением объектов, описана в field.h. Отрисовка кадров и расчет времени для обновления физики реализованы в mainwindow.cpp с использованием QPainter и QTimer, которые непрерывно пересчитывают координаты, скорости и углы поворота фигур. Управление симуляцией осуществляется через графический интерфейс, где кнопка «Старт/Стоп» запускает или приостанавливает таймер перерисовки окна и последующих вычислений.

## Lab3 - Консольное приложение на C++ для решения задачи о максимальном потоке в графе с использованием алгоритма на базе поиска в ширину.
Описание: Реализована генерация случайного графа и алгоритм поиска максимального потока (пропускной способности сети) между начальной и конечной вершинами с использованием обхода в ширину (BFS) и обновления остаточных пропускных способностей ребер. По итогу работы программа выводит в консоль матрицу смежности сгенерированного графа и вычисленное значение максимального потока.
